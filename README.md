# PizzUM & BurgUM

Aplicación web desarrollada con Spring Boot orientada a la gestión de pedidos de pizzas y hamburguesas.

## Descripción

PizzUM & BurgUM es un proyecto académico enfocado en el desarrollo de una plataforma web para la realización y gestión de pedidos gastronómicos.

El sistema permite administrar productos, visualizar el menú y gestionar pedidos mediante una arquitectura backend desarrollada con Spring Boot.

---

## Tecnologías utilizadas

- Java
- Spring Boot
- SQL
- HTML/CSS
- Git & GitHub

---

## Funcionalidades

- Visualización del menú
- Gestión de productos
- Creación de pedidos
- Administración básica del sistema
- Distinción de UI y funcionalidades según el usuario
- Persistencia de datos con base de datos SQL

---

## Objetivos del proyecto

- Aplicar conceptos de desarrollo backend
- Implementar arquitectura basada en Spring Boot
- Trabajar con persistencia de datos
- Desarrollar una aplicación web completa
- Practicar trabajo en equipo y organización del código
